# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

To report a problem, contact the maintainer privately through [GitHub](https://github.com/jvyctor). Reports are handled confidentially.
