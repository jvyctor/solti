Your AI coding agents, working as a team

Run Claude Code, Codex, Gemini CLI and OpenCode side by side on one canvas. A maestro delegates, agents message each other, and pipelines loop until the reviewer approves. You watch, approve and steer.

Downloadlatest release Other platforms

Uses the agent CLIs you already have, logged in to your own accounts. No API keys, no backend, no telemetry.

One canvas. A whole team.

Running four agents in four terminal windows is chaos. Here they share one canvas, talk through ropes, and hand work to each other.

🎼

A maestro that delegates

One agent splits the task and hands it to specialists. They report back with canvas_done.

🔗

Ropes are permissions

An agent only messages, reads or delegates to what it is roped to: terminals, notes, browser portals, diffs.

🌿

A git worktree per agent

Each agent works on its own branch, so no one overwrites anyone. Review, merge or open a PR from the Diff node.

📱

Approve from your phone

Pair your phone with a QR code: watch terminals, type, approve requests, interrupt.

Pipelines that loop until it's right

  • Parallel: dev and tester at the same time; the next step gets both results.
  • Loops: if the reviewer says REJECTED, go back to the dev with the review, at most 3 times.
  • Human approval: pause before shipping and approve in the app or on your phone.
  • Timeouts, a budget, recent runs, and a restore point before every run.

See the cost. Cap the spend.

  • Tokens and estimated cost per agent, from each CLI's own log.
  • A budget per workspace or pipeline: when it is reached, agents are interrupted and pipelines stop.
  • Spend per day for the last 14 days.

Know what every agent did

  • A searchable timeline per agent: what you typed, what pipelines asked, messages, conclusions.
  • Notifications when an agent finishes or needs you. Clicking one takes you to the terminal.
  • Restore points of every workspace.
